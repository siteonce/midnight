# Context

Glossary for midnight. One entry per term, one or two sentences each. Workflow terms are in the kit glossary, `.shipyard/core/glossary.md`.

- **Managed element**: The fixed or sticky element the library works on, usually a header.
- **Variant**: One styled version of the managed element's content, clipped to the sections it applies to.
- **Named section**: A page section with a `data-midnight-section` value, which names the variant shown over it.
- **Original**: The managed element's own content, kept in the `default` variant in auto mode, with its listeners intact.
- **Clone**: The copy of the original that auto mode makes for each named variant.
